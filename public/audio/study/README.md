# Ap Study Mode — Offline Audio Asset Directory

This directory is designated for offline background music files used during Study Mode focus sessions.

## Supported File Formats
- **MP3** (`.mp3`)
- **OGG Vorbis** (`.ogg`)
- **WAV** (`.wav`)

## Directory Structure by Playlist
You can place audio files directly into this directory or organize them by playlist folder:

